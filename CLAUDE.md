# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

User documentation for the Sober WooCommerce WordPress theme, built with **Astro 6 + Starlight 0.39**. Hosted at `https://docs.uix.store/sober/`. Pure documentation site — no API routes, no server code, no database. Sibling project: `uixthemes/milano-docs` uses the same stack and conventions.

## Developer commands

```bash
nvm use            # Node 22 LTS (pinned in .nvmrc)
pnpm install
pnpm dev           # http://localhost:4321/sober/
pnpm build         # production build → ./dist/ (fails on broken links)
pnpm check         # Astro type-check
pnpm exec prettier --check .
pnpm exec markdownlint-cli2
```

Pre-commit (husky + lint-staged) auto-formats and lints staged `.md` files. Do not bypass it.

## Architecture

- **Framework**: Starlight (Astro). Pages are plain Markdown/MDX in `src/content/docs/<section>/`.
- **`base: '/sober'`** in `astro.config.mjs` — all internal links/assets are prefixed. Never change this.
- **Sidebar**: sections are declared in `astro.config.mjs`; pages inside a section are autogenerated and ordered by `sidebar.order` frontmatter.
- **Links**: internal links are absolute (`/sober/<section>/<page>/`, trailing slash). `starlight-links-validator` checks them (and heading anchors) at build time.
- **Images** live in `src/assets/<section>/` (`src/assets/shared/` when used by several sections). Astro optimizes them at build; `starlight-image-zoom` adds click-to-zoom.
- **Image alignment**: a `#alignright` / `#alignleft` / `#alignrightfull` / `#alignleft50` suffix on an image URL floats it (`src/plugins/remark-image-align.mjs` + `src/styles/custom.css`). Images without a suffix are centered by default (`src/styles/custom.css`).
- **Header links** ("Get Support", "Buy Sober") come from the `SocialIcons` override in `src/components/HeaderLinks.astro`.

## Frontmatter (every page)

```yaml
---
title: Install Sober Theme # required
description: Upload the Sober theme... # meta description, required, ≤160 chars
sidebar:
  label: Step 2 - Install Theme # optional, sidebar text if different from title
  order: 2 # position in section
---
```

## Callouts

Use Starlight asides (`:::note`, `:::tip`, `:::caution`, `:::danger`, optional custom title `:::caution[Important]`). Do not use docsify syntax (`?>`, `!>`, `> [!NOTE]`).
