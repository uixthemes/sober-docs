Thank you for purchasing Sober! We are very pleased that you have chosen Sober for your website, you will not be disappointed!

New to Sober? This page gives you the lay of the land. Use the search field at the top of the page at any time to jump straight to an answer, or follow the guide below in order to get from a fresh WordPress install to a site that looks like our demo.

Sober can only be used with WordPress, and we assume that you already have WordPress installed and ready to go. If you do not, please follow this link to go to [wordpress.org](http://wordpress.org) to download and install the latest version of WordPress — the next page will walk you through the rest of the requirements.

## What's In This Guide

Follow these pages in order for a complete setup, or jump to the one you need:

1. **[Before Install](/sober/getting-started/before-install/)** – Read this before you start. It covers the WordPress, PHP and MySQL versions your server needs, and what files are included in the theme package you downloaded from ThemeForest.
2. **[Install Theme](/sober/getting-started/install-theme/)** – The main setup guide: download the theme, install and activate it, install the required plugins, configure image sizes, enable portfolio support, and import the demo content. It also includes a troubleshooting section for common installation problems.
3. **[Theme License](/sober/getting-started/sober-license/)** – Understand the difference between the Regular and Extended License, and when you need a second one.
4. **[Plugins License](/sober/getting-started/plugins-license/)** – Explains why the bundled Visual Composer and Revolution Slider plugins do not need a license key of your own.
5. **[Theme Support](/sober/getting-started/support/)** – What our support covers, how long you get it for, and how to extend it.

Once your site is up and running, the rest of the documentation covers every section of the theme in detail — Theme Options, Shop, Portfolio, Header, Footer, Sliders, and more.

## Before You Start

A quick checklist so the installation goes smoothly:

- [ ] WordPress is installed and you can access the admin dashboard – [Installing WordPress](http://codex.wordpress.org/Installing_WordPress)
- [ ] Your server meets the minimum requirements (PHP 5.6+, MySQL 5.6+, memory_limit 128M) – see [Before Install](/sober/getting-started/before-install/#requirements)
- [ ] You have downloaded the Sober package from your ThemeForest account – see [Download Theme](/sober/getting-started/install-theme/#step-1-download-theme)
- [ ] You know which license you need – see [Theme License](/sober/getting-started/sober-license/)

## Need Help?

- Search this documentation first — the search field is at the top of every page.
- Found a problem with the theme? Check the [Troubleshooting](/sober/getting-started/install-theme/#troubleshooting) section of the installation guide.
- Still stuck? Our support team is happy to help at [uix.ticksy.com](https://uix.ticksy.com/). Please read [Theme Support](/sober/getting-started/support/) before submitting a ticket so we can help you faster.
